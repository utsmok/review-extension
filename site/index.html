Evaluating AI search tools with confidence

A practical framework for assessing AI-based information search tools in academic settings — Transparent, Reliable, User-centric, Sound, and Traceable.

Install the Browser Extension

🧊 Chrome / Edge

  1. Download the latest chrome.zip from GitHub Releases
  2. Unzip the file
  3. Open chrome://extensions
  4. Enable Developer mode (top right)
  5. Click Load unpacked and select the unzipped folder

🦊 Firefox

  1. Download the latest firefox.zip from GitHub Releases
  2. Unzip the file
  3. Open about:debugging#/runtime/this-firefox
  4. Click Load Temporary Add-on
  5. Select any file inside the unzipped folder (e.g. manifest.json)

How TRUST Works

The TRUST framework evaluates AI-based search tools across five core principles, inspired by the FAIR principles for data management. Each review grades the tool on:

  • Quality gates — pass/fail checks for critical criteria
  • Scoring questions — 10 questions per principle, scored 0–3
  • Structured evidence — screenshots and annotations captured in-browser
  • HTML reports & nutrition labels — shareable, self-contained outputs
Evaluation Examples
ToolVerdictKey finding
ai2 Asta Recommended Restricts outputs to Semantic Scholar corpus, exposes reasoning chain, excels in Traceability and Reliability.
Elicit Needs review Valuable for abstract summarization, but ranking algorithm not fully disclosed, limiting Transparency.
ChatGPT / Gemini / Perplexity Not recommended Prone to citation errors and lack rigorous, verifiable academic sources — failing Reliability and Traceability.
