Evaluating AI search tools with confidence

A practical framework and browser extension for assessing AI-based information search tools in academic settings: Transparent, Reliable, User-centric, Sound, and Traceable.

How TRUST works

The TRUST framework evaluates AI-based search tools across five core principles, inspired by the FAIR principles for data management.

Each review grades a tool on:

  • Quality gates: pass/fail checks for critical criteria.
  • Scoring questions: 10 questions per principle, scored 0 to 3.
  • Structured evidence: screenshots and annotations captured in-browser.
  • HTML reports and nutrition labels: shareable, self-contained outputs.

Evaluation examples

ChatGPT, Gemini, Perplexity Not recommended Prone to citation errors and lacking rigorous, verifiable academic sources, failing Reliability and Traceability.

Chrome and Edge

Add to Chrome from the Chrome Web Store; it auto-updates on new releases.

For manual installs or other Chromium browsers, see the GitHub Releases.

Firefox

  1. Download the latest firefox.zip from GitHub Releases.
  2. Unzip the file.
  3. Open about:debugging#/runtime/this-firefox.
  4. Click Load Temporary Add-on.
  5. Select any file inside the unzipped folder (e.g. manifest.json).
