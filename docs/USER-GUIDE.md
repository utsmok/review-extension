# User Guide — TRUST Information Tool Reviews

## 1. Getting Started

Install the extension from the Chrome Web Store (or load it as an unpacked extension in developer mode). Click the extension icon in the toolbar to open the side panel. Click **"Start New Review"** and enter the name and URL of the tool you want to evaluate.

## 2. Capturing Evidence

Use the **"+ Quick Capture"** button on the Captures tab to take a screenshot of the tool you are evaluating. Each capture includes a screenshot, the page URL, and the page HTML. Add notes to describe what the capture shows. Expand the **"Tag to rubric items"** section to link captures to specific rubric questions for a stronger evidence trail.

## 3. Scoring

The Evaluation tab has two sections:

**Quality Gates** — Mandatory pass/fail thresholds for privacy & security, traceability, and accessibility. Gate failures are flagged but do not block scoring.

**Scoring Rubric** — Score each criterion on a 0–3 scale across five TRUST principles (Transparency, Reliability, Usability, Soundness, Traceability). AI-only questions are automatically marked N/A when "Tool uses AI" is unchecked. Use the **"+ Capture Evidence"** button to capture and link screenshots directly to individual questions.

## 4. Finalization

On the Finalize tab, select an overall grade (**Pass** / **Conditional** / **Fail**). Write a conclusion, list strengths and weaknesses, and add recommendations. Click **"Save Finalization"** to save.

## 5. Export

On the Metadata tab, click **"End Review & Export"**. This generates a ZIP file containing:

- An HTML evaluation report with screenshots and scores
- CSV files for metadata, rubric scores, capture log, and review conclusions
- An `evidence` folder with all capture screenshots and HTML pages

## 6. Tips

- Capture evidence as you go rather than waiting until the end.
- Use rubric tagging to link captures to specific questions for stronger evidence trails.
- Review the TRUST framework reference for scoring consistency.
